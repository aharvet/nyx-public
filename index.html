Politique de confidentialite

Cette politique de confidentialite decrit les donnees traitees par l'application Nyx, editee par Polycontext.

Derniere mise a jour : 27 juillet 2026

1. Compte utilisateur

Nyx ne demande pas la creation d'un compte utilisateur et ne vous demande pas de vous connecter. Aucune adresse e-mail, aucun mot de passe, aucun nom de profil et aucun numero de telephone ne sont collectes par l'application.

2. Donnees conservees sur votre telephone

Nyx conserve localement, sur votre appareil, certaines preferences et informations de fonctionnement afin que l'application retrouve votre etat entre deux utilisations.

  • vos favoris ;
  • votre mix personnel, y compris les sons choisis et leur volume ;
  • le dernier son charge pour la fonction de reprise ;
  • vos reponses d'onboarding et l'etape atteinte ;
  • l'indicateur de fin d'onboarding ;
  • votre preference d'activation ou non des rappels ;
  • la date de debut de l'essai gratuit, pour calculer un rappel local de fin d'essai.

Ces donnees restent sur le telephone. Elles ne sont pas envoyees a un serveur de Polycontext d'apres le code actuellement present dans l'application.

3. Notifications et rappels

Nyx peut vous demander l'autorisation d'afficher des notifications uniquement lorsque vous activez un rappel. Les rappels sont programmes localement par le telephone lui-meme. Le code de l'application ne met pas en place de token push, de serveur d'envoi, ni de notifications distantes.

En pratique, le rappel de fin d'essai est une notification locale. Si vous refusez l'autorisation, l'application continue de fonctionner, mais le rappel n'est pas programme.

4. Achats integres et abonnement

Sur iPhone et iPad, Nyx utilise les achats integres de l'App Store pour proposer l'abonnement Premium. Le traitement du paiement est gere par Apple. Nyx n'accede pas a vos donnees de carte bancaire.

Nyx utilise egalement RevenueCat pour recuperer les offres d'abonnement disponibles, lancer l'achat integre et verifier si un droit Premium est actif sur l'appareil.

Le code de l'application ne transmet pas de compte utilisateur maison a RevenueCat. D'apres la documentation officielle de RevenueCat, cela signifie qu'un identifiant technique anonyme peut etre genere par leur service pour gerer l'etat de l'abonnement.

5. Ce qui part vers un serveur

D'apres le code actuellement present dans l'application, Nyx ne contacte pas de serveur exploite par Polycontext.

Les seuls services externes effectivement visibles dans le code sont les suivants :

  • Apple, pour les achats integres sur iOS ;
  • RevenueCat, pour la gestion technique des offres et des droits d'abonnement.

Aucun autre service tiers d'analyse, de publicite, de mesure d'audience, de crash reporting, de chat, de connexion, de base de donnees distante ou de backend applicatif n'a ete trouve dans le code examine.

6. Permissions et donnees non collectees

Nyx lit et joue des ressources audio integrees a l'application, mais le code bloque explicitement la permission microphone sur Android et ne met pas en place d'enregistrement audio. Aucun compte, aucune geolocalisation, aucun carnet d'adresses, aucune photo, aucune camera et aucun suivi publicitaire n'ont ete identifies dans le code examine.

7. Duree de conservation

  • Les preferences et donnees locales restent sur votre appareil jusqu'a leur suppression par l'application, par vous-meme, ou lors de la desinstallation.
  • Le rappel local de fin d'essai reste programme jusqu'a son declenchement, sa desactivation dans les reglages, ou l'annulation des rappels.
  • Les donnees traitees par Apple et RevenueCat relevent de leurs propres politiques de conservation et de confidentialite.

8. Vos choix

  • Vous pouvez refuser l'autorisation de notifications.
  • Vous pouvez desactiver les rappels dans les reglages de Nyx.
  • Vous pouvez effacer les donnees locales en supprimant l'application ou, le cas echeant, via les fonctions de reinitialisation prevues dans l'application.
